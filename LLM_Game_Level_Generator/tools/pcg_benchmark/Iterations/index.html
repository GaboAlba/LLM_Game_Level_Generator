PCG Benchmark Report

Comparing LLM-generated levels against a non-LLM random baseline.

What is being evaluated

For each game variant the benchmark takes a set of LLM-generated levels and an equally sized non-LLM baseline (levels sampled randomly from the same content space). Both sets are scored against the same control targets so the comparison is fair. The goal is to determine which method produces better levels.

How it is measured

Every level set is scored on three metrics, each reported as a fraction in [0, 1] (higher is better):

MetricMeaning
QualityFraction of levels that are valid / playable (e.g. solvable, correctly connected, right number of objects for that game).
DiversityFraction of levels that are sufficiently different from the others in the set (avoids near-duplicate output).
ControlabilityFraction of levels that match the requested control targets (e.g. a target path length or object count).

Each iteration aggregates these per variant, declares a winner per metric, and an overall winner (the method that wins the most metrics). Raw per-map and per-variant data is exported as CSV next to each iteration for deeper analysis.
